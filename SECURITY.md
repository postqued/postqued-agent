# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [hello@mentign.com](mailto:hello@mentign.com). Include reproduction steps and the affected component, but do not send Postqued API keys, social account tokens, or other live credentials.

Do not disclose a vulnerability in a public GitHub issue before it has been investigated and addressed.

## Credential safety

Postqued API keys are secrets. Store them only through Claude's secure plugin configuration, rotate any key that may have been exposed, and never commit one to this repository.
